# Changelog

All notable changes to DaVinciTranslator are documented in this file.

## Unreleased

### Added

- Whisper integration for speech-to-text transcription
- Word-level timestamp support
- Automatic English SRT subtitle generation
- English-to-Italian subtitle translation
- DaVinci Resolve terminology corrections
- Modular application structure
- Subtitle grouping and translation distribution logic
- Support for MP4, MOV, MKV and AVI video files
- Automatic output directory management

### Improved

- Subtitle segmentation based on duration and line length
- Handling of short subtitle blocks
- Preservation of natural sentence structure
- Distribution of Italian translations across original subtitle timings
- Error handling during translation
- Project documentation and README

### In Progress

- Improving subtitle segmentation quality
- Improving translated subtitle distribution
- Preventing unnatural grammatical splits
- Automated subtitle quality tests
- Translation reliability improvements
