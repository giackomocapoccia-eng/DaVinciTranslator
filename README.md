# DaVinciTranslator

DaVinciTranslator è un'applicazione Python che automatizza la creazione di sottotitoli per DaVinci Resolve.

## Features

- 🎬 Rilevamento automatico del video
- 🎵 Estrazione audio con FFmpeg
- 🧠 Trascrizione con Whisper AI
- 🌍 Traduzione automatica
- 📄 Generazione di sottotitoli EN e IT
- 🎞️ Compatibile con DaVinci Resolve

## Technologies

- Python
- FFmpeg
- OpenAI Whisper
- Deep Translator
